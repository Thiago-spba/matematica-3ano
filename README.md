# Matemática serve pra quê?

Site de estudo e motivação para os alunos do **3º ano do Ensino Médio**, produzido para as aulas de Orientação de Estudos de Matemática.

**Professor:** Thiago, professor de Matemática
**Escola:** E.E. Moacyr Amaral

## Acesse o site

**https://thiago-spba.github.io/matematica-3ano/**

Funciona no celular, no tablet e no computador. Não precisa instalar nada nem fazer login.

## O que você encontra

- **Para que serve:** exemplos reais de matemática na vida pessoal (parcelamento, salário, desconto) e no trabalho (obra, transporte, saúde), com as contas passo a passo.
- **Faça as contas:** dois simuladores interativos. Um mostra quanto custa parcelar uma compra. O outro compara juros simples e juros compostos.
- **Atualidades e curiosidades:** Provão Paulista, OBMEP, Khan Academy e curiosidades do dia a dia.
- **Como estudar:** lista de hábitos de estudo para marcar, com barra de progresso.
- **Vídeos:** atalhos de busca no YouTube com os assuntos da aula.
- **Teste rápido:** três questões com explicação de cada resposta.

## Aviso para os alunos

A **Khan Academy** e a **tarefa** valem para a **média do 4º bimestre**.

## Tecnologias

- HTML, CSS e JavaScript puro, em um único arquivo (`index.html`)
- Sem dependências e sem coleta de dados dos alunos
- Fontes do Google Fonts, com fontes alternativas caso não carreguem
- Tema claro e escuro automático, conforme o aparelho
- Hospedagem gratuita no GitHub Pages

## Como atualizar

1. Edite o arquivo `index.html` neste repositório.
2. Salve a alteração com **Commit changes**.
3. Em alguns minutos o site é atualizado automaticamente.
